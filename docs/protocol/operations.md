# 流控、持久化与安全

## 流控

- **额度。**未确认的帧最多保留 `credits` 个（除非 `hello` 回复另有说明，否则为 2）。`ack` 携带窗口已绘制的最高帧 `s`，并覆盖此前的所有帧：Tern 每绘制一帧就确认一次，因此若它把某一帧与下一帧一并应用和绘制，就不会单独确认前一帧。等待 `ack` 时，持续将差异合并到待处理 ops 列表中：合并同一 id 上的 `set`，并合并 `text` 追加；收到 `ack` 后发送一帧。响应快的窗口会看到每一帧；响应慢的窗口、繁忙的守护进程或 ssh 延迟则会看到更少但更大的帧，而且 pty 不会被塞满。额度取代渲染计时器和更新合并机制。
- **谁来确认。**绘制 surface 的窗口发送 `ack`。没有窗口显示窗格时（会话已分离），不会有 `ack` 到达：保留待处理 ops，待窗口连接后，由该窗口绘制当前文档并确认。以 `listen:false` 打开的 surface 不会收到 `ack`，因此发送时不受额度限制。
- **流式传输。**将文本作为 `md`、`ansi` 或其他文本节点上的 `text append` ops 进行流式传输：线上只传输新增字节；`md` 节点则从最后一个未闭合块开始重新渲染。
- **定稿。**只要你还可能更改某个节点，就保留它的 *id*，但无需保留其完整描述。`settle` 后，停止对该子树做差异比较，并丢弃缓存的描述；之后若要更改，则按 id 发送定向 ops（`set`、`text replace`，或 `del` 后再 `add` 重建的子树）。这样，你的内存占用与文档的活动部分成正比，而不是与历史记录成正比。之后对已定稿子树执行的 op 会清除被触及节点及其所有祖先上的提示，因此完成后要再次对顶层块执行 `settle`，否则 [保留](#保留)机制无法将其逐出。
- **时长。**持续时间以年龄值传输，因此无需让时钟保持同步（[时间与动画](documents.md#时间与动画)）。

## 保留

surface 的锚点只有一个网格行，因此无法仅凭回滚区长度来限制其大小。Tern 为每个窗格分配 surface 预算：默认 64 MiB 文档状态；估算方式是将每个节点的 id、props 和固定的每节点开销相加，并汇总该窗格的所有 surface 和命令块。每当帧、样式表或关闭操作使窗格超出预算时，按以下顺序逐出内容：

1. 整个逐出已关闭的 surface 和已结束的命令块，优先最旧的。
2. 逐出开放 surface 的 `main` 中最旧的、已定稿的顶层子节点。只有子节点本身已定稿时才计入，拥有已定稿后代的节点不计入。若 surface 正在监听，Tern 会为每个被逐出的节点报告 `gone` 事件（`{"ev":"gone","sf":…,"ids":[…]}`）；之后对已逐出 id 执行的 op 会因节点未知而被拒绝。

若没有剩余的已定稿内容，窗格就会继续超出预算。已关闭的 surface 也会在其锚点行离开回滚区时整体逐出。

应用一帧所需的 Tern 时间与其 ops 数量成正比；布局只会对变更的子树增量执行；较长的 `main`、`list`、`code`、`ansi` 和 `md` 内容会被虚拟化：对回滚区中向上 10 000 个块的内容执行 op 时，无需布局该块与视口之间的任何内容。

## 持久化

- 窗格的 screen 持有 surface 文档。在 Tern 会话中，会话守护进程的 screen 保存这些文档，并向每个已连接的窗口发送相同字节，因此文档在窗口重启后仍然存在，就像网格内容一样。
- 窗口连接到正在运行的窗格时，会收到一份快照；快照通过正常解析器重放：先发送带有你的程序 `app` 和 `features` 的 `hello`，然后逐个发送 surface（先发送已关闭的），作为合成的 `o`（包含其 mode、`listen`、`closable`、`title` 和 `role`），接着发送其样式表（`s`），再发送一帧，其中使用你最后的 `s` 添加整个文档，随后是已定稿节点的 `settle`、焦点，以及挂起时的 `suspend`。已关闭的 surface 会在之后收到自己的 `x`（`keep:true`）。Tern 计时的每个年龄值（包括 `elapsed`、`tool` 和 `agent` 计时器、倒计时）都会改写为快照时间。重放过程中，Tern 发给你的程序的所有回复都会被丢弃。
- 分离后重新连接时，活动 surface 会继续工作：你的程序继续向 pty 写入（受额度限制），新窗口则绘制当前文档。
- 若守护进程停止（崩溃或重启）后恢复窗格，会启动一个新的 shell。其 inline 和 flow surface 以及命令块会以只读方式在回滚区中恢复为已关闭状态，位置与原锚点行一致；`screen` surface 不会恢复。
- Blob 按 SHA-256 存储在磁盘上（Tern 的缓存目录 `blobs/`），因此快照或恢复的窗格可以显示图像，而无需程序重新发送；程序重启后也可以通过 `blobs` 查询找到这些内容。
- 仅视图状态（折叠、控件切换、滚动位置）属于窗口，不会包含在快照中。你应将需要保留的状态同步到 props。

## 调试

- **录制。**将读写的每条 TSP 消息都连同时间戳记录为 JSONL 行 `{"t":ms,"dir":"out"|"in","verb":"f","params":{…},"body":{…}}`（omp 使用 `PI_TUI_TSP_RECORD=<file>` 写入）。
- **重放。**Tern 的场景命令 `surface-play "<file.jsonl>" [from <frame>] [until <frame>] [paced [<times>]]` 会将录制中的 `out` 消息（`o`、`t`、`s`、`f`、`x`、`b`）输入焦点窗格。`<frame>` 可以是帧 `s`，也可以是某个 surface 的 `<sf>#<s>`；`until` 在该帧之后停止，`from` 则从该帧之后开始，因此第二次播放可以接续第一次。不使用 `paced` 时，整个范围会落在同一帧中；使用 `paced` 时，则按录制时的节奏播放，速度为 `<times>` 倍（默认为 1）。手写的 `{"dir":"out","verb":"osc","body":"2;Title"}` 行会作为普通 OSC 播放；`pty` 行的 body 会原样打印，因此录制可包含 surface 周围的输出。首次播放会重启窗格，并以一个忽略 Tern 回复的替代程序运行。有关运行场景和控制套接字，请参阅[调试](../guides/debugging.md)。
- **检查。**控制套接字的 `tree` 命令会列出某个 surface 的元素；这些元素可通过 `o` 的 `role` 找到，其区域带有 `data-surface`（`tree "[data-surface='omp.session']"`）。`css` 则列出已安装的样式表，包括以 `tsp:<scope>:<name>` 命名的样式表；其中 `<scope>` 是视图的 `data-scope` 标记（`sf1`、`sf2`、…）。

## 安全与限制

- 不支持脚本和原始 HTML。`el` 根据固定标签列表和属性允许列表构建元素（[HTML 元素](../elements/el.md)）；Markdown 中的原始 HTML 会作为字面文本绘制。
- 程序 CSS 只能作用于自身 surface 内部，不能加载任何内容（`url()`）、逃出窗格（`position: fixed`）或引入字体：Tern 会丢弃 `url()` 和 `position: fixed` 声明，并通过 `error` 事件报告；同时忽略 `@font-face` 规则（[样式表](theme.md#样式表)）。Span 和 props 使用令牌，而不是原始颜色值。
- 链接的行为类似 OSC 8 超链接：悬停时显示，只有明确操作后才会打开。`file://` 链接仅限路径；不会执行命令。
- 事件只携带程序创建的 id，以及用户选择的值。输入的文本会作为 pty 输入传给你，而不会作为事件发送，但有两种选择启用的例外：原生编辑的 `edit` 事件（`edit` 功能），以及用户或 Carly 请求的 `send`（`send` 功能）（[输入与事件](input.md#原生编辑)）。

| 限制 | 值 |
| --- | --- |
| 单个 blob | 解码后 16 MiB（更大的 blob 会被拒绝并触发 `error`） |
| 每个 screen 保留的 blob | 256 MiB；超出后，未被引用的 blob 会按最近最少使用顺序逐出 |
| 磁盘上保留的 blob | 1 GiB；守护进程启动时，最久未显示的 blob 会被逐出 |
| 每个 surface 的节点数 | 200 000，包含根节点（达到上限的 `add` 会被拒绝并触发 `error`） |
| 深度 | 64 层 |
| 每个 surface 的样式表 | 总计 256 KiB CSS（超出限制的样式表会整体被拒绝） |
| 单个 APC 字符串 | 262 144 字节；Tern 会静默放弃更长的字符串。块主体的大小应不超过 `hello` 中的 `apc`（65 536） |
| 单条分块消息 | 帧拼接后为 400 000 000 字节，其他消息为 24 MiB；空闲 1 s 或被另一条 TSP 消息打断的序列会被丢弃并触发 `error` |
| 每个窗格的 surface 状态 | 默认 64 MiB（[保留](#保留)） |
